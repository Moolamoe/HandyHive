HANDYHIVE CONTRACTORS — GITHUB PAGES EDITION

1. Extract this ZIP.
2. Upload index.html, .nojekyll and the admin folder into your GitHub repository root.
3. In repository Settings > Pages, select Deploy from a branch, select your branch and / (root), then Save.
4. Open the Pages URL shown in GitHub. For a project repository the URL includes /repository-name/.
5. Open that URL followed by admin/ to edit photos. Example: https://USERNAME.github.io/REPOSITORY/admin/

PHOTO EDITING
Choose an image location, select a JPG/PNG/WebP photo and save it. Changes are stored in IndexedDB in this browser only. To make the edits visible to everyone, use Download updated website (ZIP), extract it and commit its contents to the same repository. The export embeds your photos in both HTML files. No external JavaScript libraries or image hosting are required.

IMPORTANT LIMITATIONS
GitHub Pages is static hosting. /admin is a local photo editor, not an authenticated server or a shared inbox. Opening /admin does not grant write access to the repository. Other visitors cannot change the published site; only a repository commit can do that. Keep your repository access secure.
Quotes open WhatsApp with the entered details; the visitor must press Send. Photos previewed in the form are NOT sent automatically. Attach them manually in WhatsApp. There are no background email notifications or shared quote storage.

index.html includes its CSS, JavaScript and initial images and can be opened directly for viewing. Use GitHub Pages or a local web server for the admin ZIP export. Existing uploads in the separately hosted website are not included unless they were already embedded in the source; add your chosen photos in this editor.
